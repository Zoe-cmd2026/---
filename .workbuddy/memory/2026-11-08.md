## 贪吃蛇小游戏（index.html）
- 交付单文件 `index.html`，纯原生 HTML/CSS/Canvas JS，无外部依赖，双击即可离线运行。
- 技术要点：20x20 网格 + devicePixelRatio 适配；requestAnimationFrame 定步长循环（accumulator + dt 截断 120ms）；prevSnake/current 插值实现平滑移动；输入队列防 180° 掉头；先移尾巴再判自身碰撞。
- 功能：四档速度（随分数自动提速）、穿墙模式、音效开关（Web Audio 合成）、最高分 localStorage、粒子/浮分特效、暂停/重开/失焦自动暂停、移动端滑动 + 虚拟方向键。
- UI 为浅色主题，圆角卡片，与当前 IDE 主题一致。
- 已验证：JS 语法、DOM 引用完整性、无头模拟主循环（撞墙结束 / 穿墙 500 帧存活 / 吃食物计分与 best 持久化）全部通过。
